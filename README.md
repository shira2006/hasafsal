# הספסל

אפליקציית מפה (PWA) בעברית למציאת ופרסום חפצים שהושארו ברחוב או על ספסל.

- פריסה: GitHub Pages (Settings -> Pages -> Deploy from branch -> main / root)
- נתונים: Supabase. הריצו את `supabase.sql` ב-SQL Editor ומלאו את `config.js`.
- בלי הגדרות Supabase האפליקציה עובדת במצב דמו מקומי.
- התחברות עם Google: ראו `auth.js`.
